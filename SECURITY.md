# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to **security@nomatron.io**. Do not open a public issue or pull request for a vulnerability.

Include what you found, the provider version, the Terraform version, and steps to reproduce. Do not include real credentials or customer data.

We will acknowledge your report, investigate, and tell you when a fix is released. Please give us reasonable time to fix the issue before you disclose it publicly.

## Scope

This policy covers the Terraform provider in this repository. There is no bug bounty programme.

## Supported versions

Security fixes are made in the latest released version.

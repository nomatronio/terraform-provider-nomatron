# Nomatron Provider

The Nomatron provider lets Terraform manage [Nomatron](https://nomatron.io) resources as code.

[Nomatron](https://nomatron.io) is a deployment control plane for HashiCorp Nomad. It helps platform teams operating Nomad make deployment workflows governed, auditable, and repeatable.

Use this provider to provision organizations, applications, environments, jobs, variables, RBAC objects, GitHub App integrations, Nomad clusters, service accounts, short-lived credentials, and operational actions through the Nomatron API.

Common provider use cases include:

- Bootstrapping Nomatron organizations, users, groups, roles, and service accounts.
- Creating applications, environments, jobs, variables, and approval policies as code.
- Registering Nomad clusters and GitHub App integrations used by Nomatron deployments.
- Reading existing Nomatron resources into Terraform modules.
- Minting ephemeral Nomatron agent and service account tokens without storing raw token values in Terraform state.
- Running operational Terraform actions such as importing Nomad jobs or creating speculative plans.

For product details, visit [nomatron.io](https://nomatron.io). For platform documentation and guides, start from the [Nomatron website](https://nomatron.io).

## Example Usage

```terraform
terraform {
  required_providers {
    nomatron = {
      source  = "nomatronio/nomatron"
      version = "0.4.1"
    }
  }
}

provider "nomatron" {
  address = "http://localhost:4649"
  token   = var.service_account_token
}
```
